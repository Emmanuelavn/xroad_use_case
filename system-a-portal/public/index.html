Date limite : 30 Septembre 2026

I

Conditions d'éligibilité

Être de nationalité béninoise. Être titulaire d'un diplôme de Licence ou équivalent. Avoir un casier judiciaire vierge. Justifier d'un bon état de santé.

II

Documents requis

Numéro Personnel d'Identification (NPI). Numéro de diplôme délivré par un établissement agréé. Pièce d'identité valide.

III

Frais de candidature

Un droit de quittance de 10 000 FCFA est exigé. Paiement accepté : Moov Money, MTN Mobile Money, Carte bancaire, CEET Kolo.

IV

Processus de sélection

Vérification de l'identité via l'ANIP. Contrôle du casier judiciaire via le Ministère de la Justice. Authentification du diplôme via la DGES.

Architecture Réseau Distribuée

Séquence d'appels lors d'une candidature

1
A → B Le Portail envoie la demande à l'ANIP
POST https://localhost:3001/api/v1/concours/verifier
Auth: Certificat client mTLS Portal-Concours
Body: { "npi": "11111111111111", "numero_diplome": "DIP-LIC-2026-001" }
2
B vérifie l'identité L'ANIP cherche le NPI dans son registre
→ Vérifie que le NPI existe
→ Vérifie que la nationalité est "Béninoise"
→ Si OK, lance les vérifications Justice et DGES
3
B → C L'ANIP interroge le casier judiciaire
GET https://localhost:3002/api/v1/justice/casier/11111111111111
Auth: Certificat client mTLS ANIP-Registry
Réponse: { "statut_casier": "VIERGE" }
4
B → D L'ANIP vérifie le diplôme
POST https://localhost:3003/api/v1/dges/diplome/verifier
Auth: Certificat client mTLS ANIP-Registry
Réponse: { "statut": "AUTHENTIQUE", "npi_titulaire": "11111111111111" }
5
B → A L'ANIP renvoie le résultat consolidé au Portail
Réponse: {
  "succes": true,
  "candidat": { "npi", "nom", "prenoms", "nationalite" },
  "casier": { "statut_casier": "VIERGE" },
  "diplome": { "statut": "AUTHENTIQUE" }
}
6
A → Candidat Le Portail affiche le résultat et propose le paiement
Si tout est OK → le candidat paie 10 000 FCFA → reçoit sa convocation.
Si un vérification échoue → le candidat voit le motif du refus.

Sécurité M2M

Auth: mTLS — Certificat client signé par CA interne
Ex: CN=ANIP-Registry → Justice / DGES
Ex: CN=Portal-Concours → ANIP

Toutes les requêtes inter-systèmes sont protégées par des certificats client mTLS signés par une autorité de certification interne. Chaque système possède un certificat unique (CN) et ne communique qu'avec les systèmes autorisés. Le Portail (A) n'a jamais d'accès direct aux bases de la Justice (C) ou de la DGES (D). Il ne reçoit qu'un statut consolidé par l'ANIP (B).

Persistance des données

B — ANIP : registre des personnes (NPI, nom, nationalité)
C — Justice : casiers judiciaires (statut VIERGE / NON_VIERGE)
D — DGES : diplômes (numéro, grade, filière, année)
A — Portail : inscriptions, paiements, convocations

Chaque système persiste ses données dans un fichier data.json local.
